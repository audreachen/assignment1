# Album Journeys: presentation walkthrough

Persona: Sam, a Columbia College junior who explores New York and goes for self-paced runs. Sam loves music but keeps replaying the same playlist. They want a complete album worth spending a run with and a way to remember the ones that worked.

1. Start at /journey. Explain the problem in Sam’s words: “I have forty minutes to run and I’m tired of picking individual songs.”
2. Show the founder’s recommendations. Explain how contrasts and song-level peaks can support an enjoyable run without requiring tempo synchronization.
3. Choose a duration and desired feeling. Inspect a recommendation and the duration tradeoff. Open Jubilee and its full-album Spotify player.
4. Return to the matcher, sign in through My Sticker Book, and describe the intended run. Generate the AI visual soundtrack card. Explain that this is expressive generated media, not measured album or fitness data.
5. Rate the generated card. Reload saved cards to show persistence. Prompts and provider outputs remain in the generation audit; new ratings reference the completed generation request.
6. After the imagined run, save Jubilee as “Ran with it” or “Would run with again,” add a date and a moment that worked, then reload the private journal.
